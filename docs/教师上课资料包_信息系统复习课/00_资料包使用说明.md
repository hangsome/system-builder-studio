## 二、课前准备

1. 教师电脑打开 `01_课堂链接导航.html`。
2. 投屏优先打开：`老师上课带学生用_活动页面.html`。这页是课堂主线；服务器画布只作为操作环境。
3. 给学生统一入口：`http://159.75.213.93/system-builder/openclass`
4. 教师后台查看入口：`http://159.75.213.93/system-builder/teacher`
5. 如需收集活动页中学生每个环节的答案，先运行 `08_课堂活动提交服务/app.py`，再用带 `api=` 参数的活动页地址发给学生。
6. 如需讲解 Flask 后台真实页面，打开 `07_教师后台查看数据页面.html`，或运行 `06_Flask后台服务示例/app.py` 后访问 `http://127.0.0.1:5000/teacher`。
7. 学生提交画布时只填姓名，不再填座号或详细说明。

## 三、课堂主线

1. 情境导入：由“谁来搭建这个系统”引出“人”是信息系统组成部分。
2. 硬件搭建：教师带学生打开半成品画布，先观察基础硬件框架，再让学生补充用户端。
3. 软件分析：讲 micro:bit 端和 Flask 端，区分 `GET /upload?id=...&val=...` 上传与 `GET /` 查询。
4. 运行排错：先试运行发现引脚不一致；学生回到画布看实际引脚，再修复代码或连线。
5. 数据与总结：观察 sensorlog 新增、阈值报警、故障阻断，归纳五个组成部分。

## 四、关键口径

- 不要提前告诉学生“必须改成 pin1 / pin2”。课堂口径是：**代码引脚必须与画布连线对应**。
- 学生可以改代码，也可以改画布连接；只要对应得上，系统就能运行。
- 查询数据使用 Flask 首页 `/`，浏览器 URL 填：`http://192.168.1.100:5000/`
- micro:bit 上传数据使用 `GET /upload?id=1&val=温度值`，其中 `id` 表示传感器编号，`val` 表示温度值。
- 浏览器/手机查看数据使用 `GET /`。
