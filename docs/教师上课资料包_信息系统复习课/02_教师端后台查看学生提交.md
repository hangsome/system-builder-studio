
# 教师端后台查看学生提交说明

## 入口

- 教师后台：http://159.75.213.93/system-builder/teacher
- 默认教师账号：`teacher01`
- 默认教师密码：`Teacher@123`

> 如果你已经在服务器上修改过教师账号或密码，以现场实际账号为准。

## 课堂中怎么用

1. 学生从 `http://159.75.213.93/system-builder/openclass` 进入。
2. 学生完成画布、代码或连线修复后，点击右上角“提交作业”。
3. 提交弹窗只填写“姓名”。
4. 教师打开后台，进入“提交记录/学生提交”区域。
5. 重点查看四类证据：
   - 学生姓名。
   - 自动总分和分项得分。
   - “查看画布”中的组件、连线、代码。
   - 运行日志中是否出现 `GET /upload?id=...&val=...`、`sensorlog 表新增`、`GET /` 查询。

## 自动评分关注点

| 维度 | 课堂含义 | 判断标准 |
|---|---|---|
| 画布组件与连线 | 硬件和网络结构是否完整 | 基础链路、用户端、服务器和数据库是否形成数据通路 |
| 代码关键修改 | 软件是否与硬件对应 | 传感器读取引脚、蜂鸣器控制引脚是否与画布一致 |
| 运行与数据流 | 系统是否真正跑通 | GET 上传 id/val、数据库新增、超阈值报警、GET 查询 |
| 用户端补全 | 人如何访问系统 | PC、浏览器、手机/移动终端是否补充 |

## 课堂点评建议

- 对只改代码的学生：强调“软件要适配硬件连接”。
- 对只改连线的学生：强调“硬件连接也可以反向适配既有程序”。
- 对数据库有记录但蜂鸣器不响的学生：重点检查执行器 IO 引脚与代码写入引脚。
- 对浏览器看不到数据的学生：重点检查地址栏是否填写 `http://192.168.1.100:5000/`，以及 Flask 服务器是否启动。
