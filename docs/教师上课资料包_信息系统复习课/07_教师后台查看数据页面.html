教师后台查看数据页面

本页说明教师课中如何查看三类数据：课堂活动页的分环节作答、服务器系统中的学生提交画布和自动评分，以及 Flask 后台服务中的温度数据库记录。

正式公开课建议优先使用课堂活动提交后台和学生画布提交后台；本地 Flask 教师页用于备课演示或解释“后台如何从数据库读取数据”。

打开课堂活动提交后台 活动页作答与参考评分 打开学生画布提交后台 画布、代码与自动评分 打开本地 Flask 教师页 温度数据与报警统计 查看 Flask 运行说明 本地服务启动步骤

一、课堂活动提交后台看活动作答

1

登录课堂活动提交后台

打开 http://159.75.213.93/activity-submit/teacher，输入课堂活动查看密码进入。

2

查看活动进度

学生在活动页提交后，后台会按姓名显示硬件搭建、软件分析、运行排错和自我评价四个环节的完成情况。

3

核对作答和参考评分

展开每个环节，查看学生原始作答、评分点和系统参考得分。

课堂证据后台看什么
硬件搭建传感器、执行器、引脚和模块功能匹配是否正确。
软件分析WiFi、服务器 IP、端口、上传路由和查看路由是否填写正确。
运行排错是否能从故障现象推导引脚、服务器、URL 或网络链路问题。
自我评价学生是否能判断自己还需要复习的环节。

二、学生画布提交后台看画布证据

1

登录学生画布提交后台

打开 http://159.75.213.93/system-builder/teacher，使用教师账号进入。

2

查看提交列表

学生从公开课入口提交后，后台会显示学生填写的姓名、提交时间、自动总分和分项得分。

3

打开提交画布

点击“查看画布”，核实该学生的组件、连线、智能终端（micro:bit）代码、Flask 代码、数据库记录和运行日志。

课堂证据后台看什么
硬件任务PC、浏览器、手机是否补全，数据链路是否完整。
软件任务GET /upload?id=...&val=...、GET /、URL、服务器 IP 和端口是否正确。
排错任务代码引脚是否与画布 DATA / IO 实际连线对应。
数据任务sensorlog 是否新增，超阈值是否触发蜂鸣器响应。

三、Flask 教师页看温度数据库

1

启动本地 Flask 服务

进入 06_Flask后台服务示例，按 README 安装依赖并运行 python app.py。

2

上传或模拟上传数据

智能终端或 curl 向 GET /upload?id=1&val=温度 发送温度数据，Flask 写入 SQLite 的 sensorlog 表。

3

打开教师查看页

访问 http://127.0.0.1:5000/teacher，查看总记录数、报警记录数、最新温度和最近 50 条记录。
