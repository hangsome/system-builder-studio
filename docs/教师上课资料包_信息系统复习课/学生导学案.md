## 一、情境导入：为什么要搭建这个系统

去年秋季，某中学食堂遇到过一次险情：早餐食材晚上存放在配餐间，工作人员下班后无人值守。一天半夜，制冷设备发生故障，第二天早上食材温度异常升高，存在变质风险，差点影响全校早餐供应。

后来，学校信息技术小组决定自己搭建一套“存储间温度监测与预警系统”：系统要能在夜间自动感知存储间温度变化；当温度超过安全阈值时，能在现场发出声音提醒，并通过物联网模块把异常信息发送给值班人员；值班人员用手机访问服务器页面，就能查看实时温度和历史记录。请先从这个情境判断：要感知温度变化，需要哪类传感器？要发出声音提醒，需要哪类执行器？

这个情境对应一个完整的信息系统。复习时要重点关注：谁使用和维护系统、有哪些硬件、软件如何控制硬件、数据如何产生和保存、网络如何让设备通信。

## 四、活动二：软件分工与关键代码

本系统的软件主要分为智能终端中的 micro:bit 端和 Flask 服务端。阅读代码时先判断“这段代码在系统中负责什么”，再考虑是否需要修改。

### 1. micro:bit 端关键语句

| 方法 / 语句 | 作用 |
| --- | --- |
| `pinX.read_analog()` | 从 X 引脚读取模拟量，常用于读取传感器数据。 |
| `pinX.write_digital(value)` | 向 X 引脚输出数字量，`value` 通常为 0 或 1，常用于控制执行器。 |
| `sleep(5000)` | 程序暂停一段时间，避免上传或刷新过快。 |
| `SERVER_IP`、`SERVER_PORT` | 指定 Flask 服务器地址和端口。 |
| `UPLOAD_ROUTE = "/upload"` | 指定 micro:bit 上传数据的服务器路由。 |
| `http_get(url)` | 用 GET 方式访问上传 URL，URL 中需要带 `id` 和 `val` 两个参数。 |
