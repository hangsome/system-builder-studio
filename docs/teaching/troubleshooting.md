# 教学版故障排查手册

## 1. 页面打不开或白屏

1. 检查是否执行过 `npm install`。
2. 执行 `npm run dev` 后确认端口未被占用。
3. 查看终端报错并优先处理依赖缺失或语法错误。

## 2. 组件连线后提示错误

1. 打开“硬件连接”页查看具体错误信息。
2. 优先检查电源与接地是否完整。
3. 检查 IOT 串口是否为 `TX->P15`、`RX->P16`。

## 3. 运行后没有日志或数据库无数据

1. 确认已点击“运行”按钮。
2. 确认服务器组件处于运行状态。
3. 检查 IOT 模块是否供电且已连接路由配置。
4. 在“代码编辑”确认接口路径与参数格式。

## 4. 浏览器页面无温度数据

1. 先看数据库 `sensorlog` 是否有记录。
2. 若数据库有数据，检查浏览器模拟页 URL 是否为 `/query`。
3. 若数据库无数据，回到日志定位上传链路中断点。

## 5. 传感器滑杆调整后无变化

1. 确认当前选中的是传感器组件。
2. 确认系统处于运行中并观察日志刷新。
3. 重新调整滑杆并检查 `运行仿真` 与 `浏览器` 两处变化。

## 6. 保存/恢复不生效

1. 先点击一次“保存”，再执行“恢复”。
2. 检查浏览器是否禁用了本地存储。
3. 若快照损坏，重新保存一份新快照。
