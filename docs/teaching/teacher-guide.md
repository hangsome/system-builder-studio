# 教师授课指南（2-4 课时）

## 1. 课程目标

1. 让学生理解信息系统的完整链路：采集、传输、处理、存储、展示。
2. 让学生独立完成一次可运行的物联网场景搭建。
3. 让学生能根据日志与数据表定位系统故障点。

## 2. 课时安排（建议）

1. 第 1 课时：系统架构与组件连线。
2. 第 2 课时：代码与数据流转仿真。
3. 第 3 课时（可选）：场景改造与异常诊断。
4. 第 4 课时（可选）：小组展示与复盘。

## 3. 课前准备

1. 运行 `npm install`、`npm run dev`，确认页面可访问。
2. 使用“空白画布”演练一次基础连线。
3. 使用“保存”创建本地快照，课前验证“恢复”可用。
4. 准备课堂投屏素材：系统架构图、流程图、实验步骤图。

## 4. 课堂脚本（10 分钟演示版）

1. 选择“教室温度监测系统”场景并讲解组件角色。
2. 打开“硬件连接”页，演示连线状态与错误提示。
3. 切到“运行仿真”，启动并观察数据上报日志。
4. 切到“数据库”，查看 `sensorlog` 表新增记录。
5. 切到“浏览器”，观察温度展示与阈值告警。
6. 点击“保存”并调整一个传感器值，再点击“恢复”回放。

## 5. 学生分组任务

1. 每组 2-4 人，按实验单完成一次完整搭建。
2. 每组必须演示一个故障排查案例。
3. 每组提交截图：连线状态、日志片段、数据库结果、浏览器结果。

## 6. 评分建议（100 分）

1. 系统搭建完整性：30 分。
2. 运行结果正确性：30 分。
3. 故障排查与修复过程：20 分。
4. 展示表达与总结：20 分。

## 7. 课后延伸

1. 新增一个传感器并接入已有数据流。
2. 修改阈值逻辑并验证告警行为。
3. 编写一段实验反思：系统瓶颈与优化方向。
