# 课堂检查清单

## 课前（开课前 30 分钟）

1. 本地环境可运行：`npm run dev` 正常。
2. 演示机可打开模拟器主页并完成一次场景载入。
3. “保存/恢复”功能可用，至少有一份可恢复快照。
4. 投屏、网络、电源和浏览器标签页准备完成。
5. 学生任务单已打印或可在线分发。

## 课中（每 20 分钟检查）

1. 学生是否能独立找到“硬件连接/代码编辑/数据库/浏览器”四个关键区域。
2. 至少 80% 小组完成无错误连线。
3. 至少 70% 小组看到数据库记录自动增长。
4. 至少 50% 小组完成一次故障注入与修复。
5. 教师留存典型问题截图用于课后讲评。

## 课后（下课前 10 分钟）

1. 每组已提交任务单与截图。
2. 教师收集高频错误点并记录复盘建议。
3. 下次课演示快照已保存。
4. 课堂资料已归档到班级共享空间。
