# 学生实验任务单

## 实验名称

信息系统搭建模拟实验：教室温度监测

## 实验目标

1. 能独立完成组件连接与系统启动。
2. 能读取并解释日志、数据库和浏览器输出。
3. 能通过故障现象反推问题组件或连接。

## 实验步骤

1. 载入“教室温度监测系统”预设场景。
2. 检查“硬件连接”页是否无红色错误提示。
3. 在“代码编辑”确认 micro:bit 与 Flask 逻辑。
4. 点击“运行”，观察“运行仿真”日志。
5. 在“数据库”查看 `sensorlog` 最新 10 条数据。
6. 在“浏览器”确认温度显示与告警状态。
7. 调整传感器值，记录变化后点击“保存”。
8. 手动改动场景后点击“恢复”，验证快照回放。

## 记录表

1. 当前温度值：______
2. 是否触发告警：是 / 否
3. 数据库新增记录条数：______
4. 本组定位的故障点：______
5. 修复方法：______

## 必做挑战

1. 人为制造一个错误连线并截图。
2. 通过验证面板定位错误并修复。
3. 对比修复前后日志差异并说明原因。

## 提交内容

1. 四张截图：连线、日志、数据库、浏览器。
2. 任务单填写完整并提交。
3. 小组 3 分钟口头汇报一次。
